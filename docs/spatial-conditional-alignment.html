What Julia Actually Encodes

The important detail in Julia was not an extra normalization before factorization. The important detail was the conditional problem itself. Julia maps observed NASC values to the nearest survey grid cells, marks those cells as hard data, and only factorizes the covariance of the remaining simulation cells.

  • dlocs: domain cells populated by the nearest observed NASC values
  • slocs: all remaining grid cells
  • z1: the hard-data values already written into domain order
  • d2: the Schur-complement conditional shift used when solving for mu_z
  • L22: the Cholesky factor of the covariance among slocs only

The R path had been doing something else: treating the entire grid as simulated, storing dlocs = integer(0), and building a full-field kriging-style conditional mean from obs - mean(obs).

R Changes

get_lungs_params() in R/funs.R now mirrors the Julia setup more closely:

  • nearest-domain assignment is done observation by observation, with later collisions overwriting earlier values just as Julia’s NearestInit() does,
  • dlocs and slocs are formed from the domain mask instead of assuming the full grid is simulated,
  • data now stores the masked domain values, not the raw observation vector,
  • mu is zero, matching the default Julia Gaussian process mean,
  • mu_x now stores the conditional shift term over slocs, not a full-grid kriging mean,
  • nonneg_lumult() now follows Julia and inserts hard data without an extra pmax() clamp.
